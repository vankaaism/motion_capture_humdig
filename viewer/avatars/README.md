# Folder avatar

Viewer otomatis memuat `avatar.vrm` dari folder ini dan menampilkannya di panel **2 · Animasi halus**.

## Avatar bawaan: `avatar.vrm`

| | |
| --- | --- |
| Model | AvatarSample_D (karakter 千駄ヶ谷渋 / Sendagaya Shibu), VRM 0.x |
| Pembuat | VRoid Project (pixiv) |
| Lisensi | **CC0** (domain publik: bebas dipakai, diubah, dan dibagikan, termasuk komersial, tanpa wajib kredit) |
| Sumber | https://opengameart.org/content/vroid-studio-cc0-models, berkas `avatarsample_d_0.zip` (diunggah pengguna "hecko") |
| Diunduh | 2 November 2026; isi zip satu berkas `AvatarSample_D.vrm` (16,8 MB), disimpan ulang sebagai `avatar.vrm` tanpa diubah |

Yang dicek sebelum dipakai:

- Halaman OpenGameArt mencantumkan lisensi **CC0** dan menjelaskan bahwa model-model ini berasal dari versi alpha VRoid Studio yang dirilis VRoid secara eksplisit di bawah CC0. AvatarSample A sampai C sengaja tidak disertakan karena syaratnya lebih ketat; sampel D sampai G tidak sama dengan sampel bernama sama di VRoid Studio versi sekarang.
- Metadata izin di dalam file VRM (`licenseName: Other`, tautan ke syarat VRoid Hub) mengizinkan: dipakai siapa saja, kekerasan dan konten dewasa diizinkan, penggunaan komersial pribadi maupun korporat, modifikasi, redistribusi, dan kredit tidak wajib. Jadi tidak ada konflik dengan CC0.

Meskipun kredit tidak wajib, README utama tetap mencantumkannya sebagai atribusi yang baik.

## Mengganti avatar

1. **Lewat viewer:** klik **Muat avatar .vrm** (berlaku sampai halaman dimuat ulang).
2. **Permanen:** ganti `avatar.vrm` di folder ini dengan avatar lain, lalu perbarui tabel di atas dan bagian Atribusi di README utama.

Sumber avatar lain:

- **Sampel CC0 lainnya** di halaman OpenGameArt yang sama (AvatarSample E, F, G, base male/female).
- **Buat sendiri di VRoid Studio** (gratis): atur warna busana yang terinspirasi kostum tari, lalu ekspor ke VRM. Avatar ini sepenuhnya milik kelompok, dan menjawab kritik soal estetika anime pada tari tradisional.
- **VRoid Hub (hub.vroid.com):** hanya model yang mengizinkan unduhan; baca syarat penggunaannya.

Jika lengan avatar baru bergerak terbalik, nyalakan **Koreksi sumbu VRM** di viewer. Untuk avatar bawaan biarkan mati.
